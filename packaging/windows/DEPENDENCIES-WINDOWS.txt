XyDesk Windows Runtime Dependencies

The XyDesk Windows bundle contains the native C++ Control Panel (`XyDesk.exe`)
and the Rust streaming engine (`xydesk-host.exe`).

1. Statically Linked Runtimes & Codecs (Embedded Inside Executables)
- MSVC C/C++ Runtime (`/MT` for `XyDesk.exe`, `+crt-static` for `xydesk-host.exe`):
  No external `vcruntime140.dll` or `msvcp140.dll` is required on clean Windows 10/11.
- Audio Codec (`libopus 1.5.2`):
  Compiled from vendored C source (`host/vendor/opus` via `host/build.rs`) and
  statically linked into `xydesk-host.exe`.
- Software Video Codec (`OpenH264`):
  Compiled from source (C + NASM assembly) and statically linked into
  `xydesk-host.exe` as the automatic fallback encoder.
- WebRTC Stack (`webrtc-rs 0.11` + `rustls`):
  DTLS, SRTP, SCTP DataChannel (`input`), and ICE/STUN/TURN are statically
  linked into `xydesk-host.exe`.

2. Windows System & GPU Driver Libraries (Dynamically Loaded from System32)
- Panel UI (`XyDesk.exe`): `user32.dll`, `gdi32.dll`, `shell32.dll`, `advapi32.dll`
- Screen Capture (`xydesk-host.exe`): `d3d11.dll`, `dxgi.dll`, `gdi32.dll`
- Hardware Video Encoding (`xydesk-host.exe`):
  - NVIDIA NVENC: `nvEncodeAPI64.dll` (provided by NVIDIA display driver)
  - AMD / Intel / NVIDIA Media Foundation (MFT): `mfplat.dll`, `mfreadwrite.dll`, `mfuuid.lib`
- Audio Loopback & Passthrough: Windows WASAPI (`mmdevapi.dll`, `ole32.dll`)
- Low-Latency Input Injection: `user32.dll` (`SendInput`)

3. Bundled Optional Hardware Drivers (`drivers/` directory in Release Installer)
- Virtual Display Driver (`drivers/IddSampleDriver/`):
  `iddsampledriver.dll`, `iddsampledriver.inf`, `iddsampledriver.cat`,
  `iddsampledriver.cer`, `option.txt`, `install.bat`, `uninstall.bat`
- Virtual Audio & Microphone Driver (`drivers/audio/`):
  `VBCABLE_Setup_x64.exe`, `vbaudio_cable64_win7.sys`, `.inf`, `.cat`,
  `install-audio.bat`, `uninstall-audio.bat`

4. Installer License Assets
- `LICENSE-XyDesk.txt` — English license text included in the installed bundle.
- `LICENSE-XyDesk-English.rtf` — English EULA in RTF format for WiX MSI dialog.
- `THIRD-PARTY-LICENSES.md` — notices for dependencies and bundled support files.

If a future build adds a non-system DLL, it must be copied into the verified
native bundle, recorded here or in the generated dependency manifest, and
included in both the MSI and NSIS artifacts. Never download a DLL at install
time or silently replace a system DLL.
