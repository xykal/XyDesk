## [HIGH]
1. `web_deploy/static/_headers:6` — tidak ada `Strict-Transport-Security`
   dan CSP tanpa `frame-ancestors` (hanya `X-Frame-Options: DENY`, yang
   diabaikan browser bila CSP ada `frame-ancestors`; tanpa keduanya modern
   clickjacking policy tidak terikat); tidak ada `object-src`.
   Fix (diterapkan): HSTS 2 tahun + preload, `frame-ancestors 'none'`,
   `object-src 'none'`, `media-src 'self' blob:` (audio sesi);
   `web/test/csp.test.js` diperluas sebagai proving test. `img-src https:`
   dibiarkan karena gambar artikel berita datang dari host eksternal
   (usulan LOW: proxy gambar lewat worker berita, lalu persempit).
2. `.github/workflows/*.yml` — 11 action dipakai dengan tag bergerak
   (`actions/checkout@v4`, `subosito/flutter-action@v2`, dst.). Tag bisa
   dipindah; kompromi upstream = kode berjalan dengan token repo.
   Fix (diusulkan, butuh resolusi SHA lewat API per action): pin ke SHA
   penuh + komentar versi; Dependabot `github-actions` untuk pembaruan.
3. `.github/workflows/release.yml` — job `prepare`, `clients`, `publish`
   tanpa `timeout-minutes` (hanya `windows-installer` yang punya); job yang
   menggantung memakan menit Actions (risiko suspensi akun yang sudah
   pernah terjadi). Fix (diterapkan): 10/30/15 menit per job.

## [MED]
4. Atribusi XyVerse tidak ada di surface mana pun (footer web, meta author,
   About Android, `--version` host, manifest). Fix (diterapkan): satu
   sumber brand per stack — `web/src/config/brand.ts`, `lib/core/brand.dart`,
   `host/src/brand.rs`; footer web, `<meta name="author">`, halaman About,
   dan baris versi host membacanya.
5. Root repo tanpa `SECURITY.md`, `PROGRESS.md`, `IDEAS.md`, `.editorconfig`,
   `CONTRIBUTING.md`. Fix (diterapkan): SECURITY.md (kebijakan disclosure),
   PROGRESS.md (mulai log hari ini; riwayat sebelumnya "tidak ada log"),
   IDEAS.md, .editorconfig. CONTRIBUTING menunggu keputusan DCO/CLA (repo
   berlisensi proprietary — lihat LOW-12).
6. Tidak ada `.github/dependabot.yml`. Fix (diterapkan): npm (web, admin,
   cloudflare, news), cargo (host), pub (root), gomod (signaling),
   github-actions; mingguan, PR digabung per ekosistem.
7. Berkas >600 baris: `host/src/screen.rs` 2271, `nvenc_types.rs` 2296
   (binding, boleh), `main.rs` 1505, `control.rs` 1170, `lib/l10n/strings.dart`
   1329, `account_page.dart` 1239, `web/src/connect_screen.tsx` 1138,
   `rtc.ts` / `rtc_service.dart` 1065, `auth_screen.dart` 1009,
   `session_page.dart` 1000, `connect_page.dart` 934. Refactor medium hari
   ini sudah memangkas App.tsx, main.rs, session_page, session_panels.
   Sisanya: usulan, satu per PR, mulai `screen.rs` (capture vs encoder).
8. i18n klien satu berkas `lib/l10n/strings.dart` (1121 string literal),
   tanpa ARB, tanpa plural/gender, tidak bisa dikerjakan penerjemah.
   Web tidak punya katalog sama sekali (string Indonesia hardcode).
   Fix: migrasi ke ARB id+en dengan `flutter gen-l10n` (item kall #4),
   web menyusul dengan katalog JSON ringan.
9. `signaling/main.go:77` — hanya `ReadHeaderTimeout`; tidak ada
   `ReadTimeout`/`IdleTimeout`/`MaxHeaderBytes`, tidak ada batas koneksi
   per IP. Cloudflare Worker `/ws` di depan menyerap L3/L4, tetapi jalur
   Go langsung (bila origin terekspos) rentan slowloris. Fix (diusulkan):
   timeouts + `MaxHeaderBytes: 16<<10` + semaphore per IP, proving test Go.

## Yang sudah benar (tidak perlu disentuh)
- OTP/login: rate limit per IP + per akun (`authstore.js:243`,
  `admin_security.js:141-174`), lockout, PBKDF2+TOTP, JWT alg/typ dicek.
- Komentar berita: 429 per fingerprint (`news/src/worker.js:341`).
- Host: control API 127.0.0.1 + bearer, pairguard brute-force, Origin
  allowlist `/ws` (Worker + Go), clippy `-D warnings`, 209 test.
- CSP `script-src 'self'` tanpa inline; tidak ada innerHTML/eval; npm audit 0.
- Build workflow: `concurrency`, `permissions` minimal, `timeout-minutes`
  di semua job, path filter.
