# XyDesk 6.11.19 — 2026-10-08

**Perbaikan hardware encoder H.264 (NVENC/MFT 60 FPS), deteksi GPU aktif akurat, pembukaan keyboard virtual Android, dan penyegaran UI kontrol overlay.**

Pembaruan besar untuk stabilitas performa streaming, akurasi perangkat keras, dan ergonomi antarmuka pengguna Android:

### 1. Akselerasi Hardware H.264 & Kecepatan 60 FPS Mulus (Host Windows)
- **Akar Masalah:** Inisialisasi encoder hardware `NvEnc` dan `MFT` sebelumnya memiliki pemeriksaan artifisial yang menolak streaming jika dimensi canvas awal berbeda dengan resolusi capture. Hal ini memaksa pipeline jatuh ke encoder CPU software (OpenH264) yang memicu frame drop, lag, dan stuttering. Selain itu, penguraian SDP menolak profil H.264 baseline/main/high non-`42e0`, memaksa fallback ke Level 31 (30 fps/720p).
- **Solusi:** Menghapus pembatasan canvas buatan pada `NvEnc` dan `MFT` sehingga encoder hardware NVIDIA (NVENC) dan Intel/AMD (MFT) langsung aktif di resolusi native dengan latensi sangat rendah (<2 ms).
- **Negosiasi H.264 & 60 FPS Default:** Penguraian SDP kini menerima profil H.264 apa pun secara dinamis dan menyetel target kecepatan default 60 FPS saat tersambung.

### 2. Deteksi GPU Aktif Akurat (hwinfo)
- **Akar Masalah:** `gpu_names()` sebelumnya membaca seluruh subkunci registry adapter secara membabi buta. Pada template VM Cloud (mis. ThinkMay), riwayat driver GPU lama (mis. RTX 3060) dan GPU baru (mis. RTX 5060) terakumulasi di registry, menyebabkan nama GPU terlaporkan ganda.
- **Solusi:** Menggunakan Win32 `EnumDisplayDevicesW` untuk memprioritaskan GPU/adapter aktif yang terpasang pada desktop (`DISPLAY_DEVICE_ATTACHED_TO_DESKTOP`), dengan fallback registry hanya untuk mesin headless.

### 3. Perbaikan Pembukaan Keyboard Virtual Android
- **Akar Masalah:** Tombol keyboard pada toolbar sebelumnya hanya memanggil `showSoftInput` dengan flag `SHOW_IMPLICIT` pada invisible dummy sink yang kerap diabaikan oleh sistem Android.
- **Solusi:** Tombol "Kibor" di toolbar kini membuka on-screen PC Keyboard HUD dan memicu pemanggilan keyboard virtual Android dengan flag `SHOW_FORCED` sehingga input teks langsung aktif.

### 4. Estetika UI Toolbar & Ergonomi Kontrol Overlay
- **Penyegaran Toolbar:** Mengembalikan desain toolbar ke gaya frosted glass khas XyDesk yang bersih, elegan, dan ringkas.
- **Ergonomi Kontrol Default:** Menyederhanakan layout kontrol on-screen default (Stick WASD, Lompat, Lari, Jongkok, Tembak/Keker, Esc, Tab) agar nyaman digunakan tanpa menutupi layar berlebihan.
