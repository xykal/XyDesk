# XyDesk 6.11.18 — 2026-10-07

**Perbaikan tampilan panel host pada Cloud GPU VM (ThinkMay, Shadow, Parsec) dan pratinjau thumbnail taskbar DWM Windows.**

Perbaikan penting untuk visualisasi antarmuka host Windows:

### 1. Perbaikan Layar Hitam / Tidak Muncul di Cloud GPU & Remote Desktop
- **Akar Masalah:** Sebelumnya, jendela native host Windows menerapkan `SetWindowDisplayAffinity(window, 0x00000011)` (`WDA_EXCLUDEFROMCAPTURE`). Fungsi ini menginstruksikan Windows Desktop Window Manager (DWM) untuk mengecualikan jendela dari seluruh API penangkap layar (DXGI Output Duplication, BitBlt, Windows Graphics Capture).
- **Dampak pada Cloud VM (ThinkMay/Parsec/Shadow):** Pada komputer cloud GPU seperti ThinkMay yang diakses 100% melalui streaming penangkap layar DXGI, perintah ini menyebabkan DWM me-render jendela XyDesk sebagai kotak hitam pekat (black screen) atau tidak muncul sama sekali di layar streaming. Demikian pula pada live thumbnail preview di taskbar Windows, popup thumbnail tampak hitam pekat.
- **Solusi:** Menghapus `WDA_EXCLUDEFROMCAPTURE` dan menyetel `SetWindowDisplayAffinity(window, 0)` (`WDA_NONE`) sehingga jendela host XyDesk dapat dirender secara normal, sempurna, dan responsif di semua lingkungan Cloud GPU VM, remote desktop, OBS, Discord screen share, dan live thumbnail taskbar Windows.
- **Inisialisasi Tampilan Jendela:** Memastikan `ShowWindow` selalu memanggil `SW_SHOWNORMAL` saat dijalankan agar jendela langsung terangkat dan fokus ke depan layar.
