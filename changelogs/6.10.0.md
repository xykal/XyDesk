# 6.10.0 — Klien Android native lengkap: Berita, riwayat, mic, kehadiran host

**Tanggal:** 2026-10-01
**Tipe:** feat client + host (mic virtual) — satu update besar

## Ringkasan Founder
Satu update besar alih-alih banyak update kecil. Klien Android native kini
setara dan melampaui web: Berita tersambung ke sumber yang sama, riwayat punya
dua tampilan dan detail per sesi, host bisa diberi nama/favorit, mic HP ke PC,
dan status online host terlihat sebelum menyambung.

## Ditambahkan
- Berita: daftar per kategori, artikel penuh (markdown + sampul), suka,
  komentar + balasan, bagikan, mode founder, cache offline, notifikasi berita
  baru (WorkManager, ~6 jam), avatar DiceBear.
- Peramban dalam aplikasi untuk semua tautan (S&K, privasi, sosial, berita).
- Riwayat: tampilan daftar/grid, saringan Semua/Berhasil/Gagal, ringkasan
  pemakaian, detail sesi dengan grafik fps/RTT (`SessionTrace`), ekspor JSON.
- Perangkat: cari, urutkan, nama panggilan, favorit, lupakan host, status
  online/offline realtime (`Presence` lewat signaling `list`/`devices`),
  sambung satu ketuk dengan password tersimpan terenkripsi.
- Sesi: cubit = zoom, 3 jari = Alt+Tab/Win+Tab, sambung ulang otomatis,
  tombol cepat tambahan, bitrate manual, pusatkan kursor, mode presentasi,
  Mic ke host dengan indikator level, label kualitas jaringan.
- Pengaturan: tab awal, tanya sebelum putus, notifikasi berita, koneksi,
  panduan gestur, halaman Tentang.
- Login: ilustrasi penuh statis; splash sederhana logo + wordmark.
- libxyadapt: `NetworkScore`, `ReconnectPolicy`, `SessionTrace`, `Semver`,
  gestur cubit/3 jari; test unit.
- Host (agen host): endpoint "XyDesk Virtual Microphone" + Mic DSP.
- Dependensi: windows 0.62, base64 0.23, typescript 7, lucide 1.x, dll.
