# XyDesk 6.11.21 — 2026-10-08

**Perbaikan koneksi stabil tanpa reset resolusi tidak diminta (menghilangkan loop "loading percobaan" pada Cloud GPU VM).**

Perbaikan stabilitas koneksi:

### 1. Pencegahan Gangguan Display Driver Saat Klien Terhubung
- **Akar Masalah:** Sebelumnya, saat sesi baru terhubung, host secara otomatis mengeksekusi `desktop_mode::request` yang memanggil `ChangeDisplaySettingsExW` untuk memaksa resolusi desktop Windows berubah. Pada lingkungan Cloud GPU VM (ThinkMay, Shadow, Parsec) dan multi-adapter, pemanggilan ini mereset driver tampilan dan seketika merusak (break) sesi capture DXGI Desktop Duplication yang sedang aktif. Akibatnya, aliran video terputus seketika setelah connected, dan klien Android masuk ke mode auto-reconnect ("loading percobaan trus gagal").
- **Solusi:** Menghilangkan pemanggilan otomatis `ChangeDisplaySettingsExW` saat inisialisasi koneksi, sehingga host mempertahankan resolusi asli desktop yang sedang berjalan tanpa merusak driver display dan capture DXGI. Klien kini terhubung dengan stabil, mulus, dan tanpa putus tak terduga.
