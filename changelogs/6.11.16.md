# XyDesk 6.11.16 — 2026-10-07

**Perbaikan login tanpa stuck (Google & Email), logo resmi XyDesk di semua platform, tata letak seimbang, dan fitur Edit Profil di Android.**

Pembaruan menyeluruh untuk pengalaman masuk akun, identitas visual, dan manajemen profil pengguna:

### 1. Login Tanpa Stuck (Google & OTP Email)
- **Host Windows (Panel Native):** Timer animasi UI (`kAnimTimer`) kini dipastikan terus berdetak selama operasi login latar belakang (`g.gateLogin`, `g.gateOtp`, `g.gateRestore`) berjalan. Sebelumnya, timer mati setelah animasi 160 ms sehingga antarmuka tampak membeku pada status "Menunggu browser…" atau "Kirim kode". Begitu browser atau server selesai memproses, panel kini langsung bertransisi seketika ke halaman utama.
- **Android APK (`LoginScreen` & `SlideToGoogle`):**
  - Tombol Google kini mendukung ketukan langsung (tap) serta geseran (slide), tanpa mewajibkan tarikan penuh >85% yang sebelumnya membuat pengguna merasa tombol tidak merespons.
  - Alur OTP email dilengkapi tombol "Ganti email" untuk memperbaiki salah ketik alamat tanpa terjebak di layar OTP, serta tombol "Kirim ulang kode" dengan umpan balik yang jelas.
  - Status pemuatan (`googleBusy`, `busy`) selalu di-reset secara aman jika terjadi pembatalan atau kegagalan jaringan.

### 2. Logo Resmi XyDesk di Semua Platform
- **Logo Vektor XyDesk:** Logo resmi berupa pita silang 3D geometris (crossed-ribbon) dengan gradasi violet-magenta-lavender dan kilau bintang kini terpasang secara resmi:
  - Di header panel host native Windows (`paintXyDeskLogoMark` / `paintLogo`).
  - Di kartu gerbang masuk host Windows (`paintGate`).
  - Di layar login Android (`XyDeskMark`), diletakkan di bagian atas secara elegan.
- Menggantikan ikon lingkaran sederhana berhuruf "Xy" dengan identitas merek asli yang konsisten di Web, Windows, dan APK.

### 3. Tata Letak Login Seimbang & Proporsional
- Menghilangkan ruang kosong berlebih (spacer 300 dp) pada layar login Android sehingga seluruh formulir masuk, logo, tombol Google, dan tautan legal tampil seimbang dan langsung terlihat di berbagai ukuran layar tanpa harus menggulir jauh ke bawah.

### 4. Fitur Edit Profil Lengkap di APK
- **Halaman Edit Profil:** Pengguna dapat mengubah nama tampilan dan foto profil langsung dari tab Akun -> Edit Profil.
- **Penyimpanan Sinkron:** Pembaruan nama dan URL foto profil dikirim ke server (`POST /auth/profile`) serta disimpan di penyimpanan aman lokal (`Store.userName`, `Store.userPhoto`).
- **Pembaruan Menyeluruh:** Nama dan foto profil yang diperbarui langsung tercermin pada kartu akun, header aplikasi, dan ruang obrolan global.
