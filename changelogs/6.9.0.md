# 6.9.0 — Client Android native, Flutter dihapus

**Tanggal:** 2026-09-30
**Tipe:** feat client — penulisan ulang + perubahan pipeline rilis

## Ringkasan Founder
Target XyDesk adalah gaming; jalur Flutter menambah lapisan tekstur dan
membatasi kontrol atas decoder. Klien Android kini native: Kotlin + Compose
(semua komponen digambar sendiri, tanpa Material), pustaka C++ `libstreamxy`
untuk protokol input dan telemetri, decoder H.264 low-latency (MediaCodec
`KEY_LOW_LATENCY`, render langsung ke Surface) dengan fallback otomatis.

## Ditambahkan
- `android-native/` — splash + VO first launch, onboarding, login OTP dan
  geser-ke-Google, bottom nav (Beranda/Perangkat/Riwayat/Akun), pengaturan
  (bahasa ID/EN, getaran, intro), toolbar sesi (keyboard IME, kualitas,
  720p/1080p, monitor, stats, putus), keyboard fisik dengan peta VK.
- `android-keystore.yml` — keystore rilis dibuat di CI dan disimpan sebagai
  secret; sidik jari SHA-1/256 di ringkasan run.
- `VERSION` — satu-satunya sumber nomor versi (menggantikan `pubspec.yaml`).

## Dihapus
- `lib/`, `test/`, `android/`, `pubspec.yaml`, `pubspec.lock`,
  `analysis_options.yaml`, `l10n.yaml`, workflow `flutter-check.yml`, job
  `check-flutter` di Build.

## Diubah
- Build job `android` membangun APK native per ABI bertanda tangan; Release
  memakai nama `XyDesk-arm64-v8a.apk` / `XyDesk-armeabi-v7a.apk`.
- Paket aplikasi `id.xyverse.xydesk` (sebelumnya `com.xystudio.xydesk`):
  pengguna harus pasang ulang.

## Belum
- Gamepad (butuh tag protokol + ViGEm di host), watchdog decoder di tengah
  sesi, dokumen di `docs/` masih menyebut Flutter di beberapa tempat.
